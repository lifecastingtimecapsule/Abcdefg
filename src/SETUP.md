# アマレット管理システム - セットアップガイド

## 🚀 初回セットアップ

システムを初めて使用する場合は、以下の手順で初期化を行ってください。

### ステップ1: システムの初期化

1. アプリケーションを起動
2. ログインページで「**初回セットアップはこちら**」をクリック
3. 初期化ページで「**システムを初期化**」ボタンをクリック
4. 管理者アカウントが自動的に作成されます

### ステップ2: 初期ログイン

初期化が完了したら、以下のアカウントでログインしてください：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 デフォルト管理者アカウント
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ログインID: admin
パスワード: amaretto2024
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

⚠️ **重要なセキュリティ注意事項**
- このアカウントはデフォルトのため、誰でも知っている可能性があります
- 初回ログイン後、すぐに新しい管理者アカウントを作成してください
- 新しいアカウント作成後、このデフォルトアカウントを���効化することを強く推奨します

## 📋 初期設定の手順

### 1. 新しい管理者アカウントの作成（必須）

1. デフォルトアカウントでログイン
2. 左メニューから「**スタッフ管理**」を選択
3. 「**新規スタッフ追加**」ボタンをクリック
4. 新しい管理者の情報を入力：
   - **名前**: あなたの名前
   - **ログインID**: 新しいログインID（例: `yamada_admin`）
   - **メールアドレス**: 一意のメールアドレス
   - **パスワード**: 強力なパスワード
   - **ロール**: 「管理者」を選択
5. 「保存」ボタンをクリック
6. 一度ログアウトして、新しいアカウントでログインできることを確認

### 2. デフォルトアカウントの無効化（推奨）

1. 新しい管理者アカウントでログイン
2. 「スタッフ管理」を開く
3. `admin` アカウントを見つける
4. 編集アイコンをクリック
5. 「**アカウント有効**」のチェックを外す
6. 「保存」ボタンをクリック

### 3. スタッフアカウントの作成

実際に使用するスタッフのアカウントを作成：

1. 「スタッフ管理」から「新規スタッフ追加」
2. 必要な情報を入力：
   - **名前**: スタッフの氏名
   - **ログインID**: スタッフ用のID（例: `tanaka_staff`）
   - **メールアドレス**: 内部認証用（ログインには使用されません）
   - **パスワード**: スタッフ用パスワード
   - **ロール**: 「スタッフ」を選択
3. 作成後、スタッフに認証情報を伝える

### 4. 拠点の設定

1. 左メニューから「**拠点管理**」を選択
2. 「新規拠点追加」ボタンをクリック
3. 店舗や拠点の情報を登録：
   - 拠点名
   - 住所
   - 電話番号
   - など

### 5. 顧客情報の登録

1. 左メニューから「**顧客管理**」を選択
2. 「新規顧客登録」ボタンをクリック
3. 顧客の基本情報を登録

### 6. 業務の開始

- **予約管理**: 顧客の予約を登録・管理
- **納期管理**: 制作物の進捗と納期を管理
- **インセンティブ管理**: スタッフの成果を確認・管理

## 💡 ログイン方法

### 通常のログイン

1. ログインページにアクセス
2. あなたのログインIDとパスワードを入力
3. 「ログイン」ボタンをクリック

### 初回セットアップ（既に完了している場合）

「初回セットアップはこちら」のリンクは、既にユーザーが存在する場合はエラーが表示されます。
通常のログインをご利用ください。

## 🔧 トラブルシューティング

### ログインできない場合

1. **ログインIDとパスワードを確認**
   - デフォルトアカウント: `admin` / `amaretto2024`
   - 大文字・小文字を正確に入力してください

2. **ブラウザのコンソールを確認**
   - F12キーを押してコンソールを開く
   - エラーメッセージを確認

3. **Supabase Edge Functionを確認**
   - サーバーが起動しているか確認
   - ネットワーク接続を確認

### 初期化がうまくいかない場合

1. **既にユーザーが存在する可能性**
   - 「ユーザーが存在します」というエラーが表示される場合、既に初期化済みです
   - 通常のログインを試してください

2. **Supabase設定を確認**
   - 環境変数が正しく設定されているか確認
   - Supabase プロジェクトが有効か確認

3. **KV Storeを確認**
   - Supabase ダッシュボードでKV Storeが正常に動作しているか確認

### デフォルトアカウントを無効化してしまった場合

新しい管理者アカウントを作成する前にデフォルトアカウントを無効化してしまった��合：

1. Supabaseダッシュボードにアクセス
2. KV Storeから `admin` ユーザーを見つける
3. `active_flag` を `true` に戻す

または、データベースを初期化して最初からやり直すことも可能です。

## 📝 補足情報

### ログインIDについて

- ログインIDは**メールアドレスではありません**
- 内部的にはSupabaseの認証にメールアドレスを使用していますが、ユーザーからは見えません
- ログイン時は必ずログインIDを使用してください

### パスワード変更について

現在、パスワード変更機能は未実装です。パスワードを変更したい場合は：

1. 新しいアカウントを作成
2. 古いアカウントを無効化

この方法で対応してください。

### バックアップについて

重要なデータは定期的にバックアップすることをお勧めします。Supabaseダッシュボードからデータをエクスポートできます。
