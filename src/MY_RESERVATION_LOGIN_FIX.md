# 予約確認ページ（/my-reservation）ログイン問題の修正

## 🔍 問題の原因

顧客の予約確認ページでメールアドレスと予約番号を入力してもログインできない問題がありました。

### 根本原因
1. **管理画面の顧客管理機能で`email`フィールドが処理されていなかった**
   - パブリック予約フォームから作成された顧客には`email`が保存されている ✅
   - しかし、管理画面から作成/編集された顧客には`email`が保存されていなかった ❌

2. **予約確認ログインエンドポイントでメールアドレスが必須**
   - サーバー側コード: `if (!customer.email) → 401エラー`
   - 顧客データに`email`フィールドがない場合、ログイン拒否される

## ✅ 実施した修正

### 1. **サーバー側の修正** (`/supabase/functions/server/index.tsx`)
- 顧客作成/更新エンドポイント（`/customers`）に`email`フィールドを追加
- リクエストボディから`email`を受け取り、顧客データに保存
- ログインエンドポイントに詳細なログ出力を追加
- メールアドレスが登録されていない場合の明確なエラーメッセージを追加

### 2. **顧客管理フォームの修正** (`/components/CustomerModal.tsx`)
- フォームの状態に`email`フィールドを追加
- UIにメールアドレス入力フィールドを追加（電話番号の隣）
- フォーム送信時に`email`を含めるように修正

### 3. **予約作成フォームの修正** (`/components/ReservationModal.tsx`)
- フォームの状態に`email`フィールドを追加
- 顧客情報セクションにメールアドレス入力フィールドを追加
- 新規顧客作成時に`email`を送信
- 既存顧客選択時に`email`を読み込むように修正
- 顧客検索結果にもメールアドレスを表示

### 4. **エラーハンドリングの改善** (`/components/MyReservationPage.tsx`)
- 404エラー：予約が見つからない場合の明確なメッセージ
- 401エラー：メールアドレス未登録の場合の対処方法を表示

## 📋 動作確認手順

### A. 新規予約でテスト（推奨）

#### 方法1: パブリック予約フォームから
1. `/reservation` にアクセス
2. 必要事項を入力（**メールアドレスを必ず入力**）
3. 予約を作成
4. 確認メールに記載された予約番号をメモ
5. `/my-reservation` にアクセス
6. メールアドレスと予約番号でログイン
7. ✅ ログイン成功し、予約情報が表示される

#### 方法2: 管理画面から
1. 管理画面にログイン
2. カレンダーまたは予約一覧から「新規予約」をクリック
3. 顧客情報を入力（**メールアドレスを必ず入力**）
4. 予約を作成
5. 作成された予約番号をメモ
6. `/my-reservation` にアクセス
7. メールアドレスと予約番号でログイン
8. ✅ ログイン成功し、予約情報が表示される

### B. 既存予約の場合

#### 既存顧客にメールアドレスを追加する方法
1. 管理画面にログイン
2. 「顧客管理」ページにアクセス
3. 対象の顧客を検索して選択
4. 「編集」ボタンをクリック
5. 新しく追加された「メールアドレス」フィールドに入力
6. 「保存」をクリック
7. `/my-reservation` で該当予約のログインをテスト

## 🐛 トラブルシューティング

### ログインできない場合の確認手順

#### 1. ブラウザの開発者ツールでログを確認
```
F12キー → Consoleタブ
```

以下のようなログが出力されます：
```
[MyReservation] ログイン試行: { email: "example@email.com", reservation_number: "abc12" }
[MyReservation] レスポンスステータス: 401
[MyReservation] エラーレスポンス: { error: "この予約にはメールアドレスが登録されていません..." }
```

#### 2. エラーメッセージの意味

**404エラー：「予約が見つかりませんでした」**
- 予約番号が間違っている
- 予約が削除されている
- 別のSupabaseプロジェクトに保存されている

**401エラー：「メールアドレスまたは予約番号が正しくありません」**
- メールアドレスが間違っている
- **顧客データにメールアドレスが登録されていない** ← 最も多い原因

**401エラー：「この予約にはメールアドレスが登録されていません...」**
- 管理画面から顧客情報を編集してメールアドレスを追加する必要がある

#### 3. サーバー側のログを確認（Supabaseダッシュボード）

Supabase ダッシュボード → Edge Functions → `make-server-fe84bde0` → Logs

以下のようなログが出力されます：
```
[予約確認ログイン] リクエスト受信: { email: "...", reservation_number: "..." }
[予約確認ログイン] 予約検索結果: 見つかりました
[予約確認ログイン] 顧客データ: { customer_id: "...", has_email: false, email_matches: false }
[予約確認ログイン] ❌ 顧客にメールアドレスが登録されていません
```

#### 4. データベースで直接確認（高度な方法）

Supabase ダッシュボード → Table Editor → `kv_store_fe84bde0`

1. **予約データを検索**
   - `key` カラムで `reservation:` を含むレコードを検索
   - `value` カラムで `reservation_number` が一致するか確認

2. **顧客データを確認**
   - 予約の `customer_id` をメモ
   - `key` = `customer:<customer_id>` のレコードを検索
   - `value` カラムに `email` フィールドがあるか確認

## 🎯 重要なポイント

1. **既存の顧客データは自動的には更新されません**
   - 管理画面から手動でメールアドレスを追加する必要があります

2. **パブリック予約フォームから作成された新しい顧客**
   - 最初からメールアドレスが保存されるため、すぐに予約確認機能が使えます

3. **管理画面で作成する新しい顧客**
   - メールアドレスフィールドが追加されたため、入力すれば予約確認機能が使えます

4. **メールアドレスは任意フィールド**
   - 入力しなくても予約は作成できます
   - ただし、予約確認ページを利用するにはメールアドレスが必須です

## 📊 確認済み事項

✅ パブリック予約フォームからの予約作成時に`email`が保存される  
✅ 管理画面の顧客管理で`email`を編集できる  
✅ 管理画面の予約作成で`email`を入力できる  
✅ ログインエンドポイントで`email`が正しく検証される  
✅ エラーメッセージが明確で対処方法が分かりやすい
