# 予約確認ページのトラブルシューティング

## 問題の診断

予約確認ページ (`/my-reservation`) が開けない場合、以下の原因が考えられます。

### 1. メール内のリンクが正しいドメインを指していない

**症状:**
- メールの「予約を確認・管理する」ボタンをクリックしても、正しいページに遷移しない
- 404エラーが表示される
- 別のドメインに遷移してしまう

**原因:**
- `APP_BASE_URL` 環境変数が設定されていない、または間違っている

**解決方法:**
1. Supabase Dashboard にアクセス
2. Project Settings > Edge Functions > Environment Variables に移動
3. 新しい環境変数を追加:
   - Name: `APP_BASE_URL`
   - Value: アプリの実際のURL（例: `https://your-app.vercel.app` または Figma Makeのプレビュー URL）
4. 環境変数を保存
5. Edge Functionsを再デプロイ（自動的に反映される場合もあります）

### 2. ルーティングの問題

**症状:**
- ブラウザで直接 `/my-reservation` にアクセスしても表示されない
- 白い画面が表示される

**診断手順:**
1. ブラウザの開発者ツールを開く（F12キー）
2. Console タブを確認
3. 以下のログが表示されているか確認:
   ```
   [App] 初期ルート: /my-reservation
   [App] 予約確認ページ表示: /my-reservation
   [MyReservation] ページ読み込み
   ```

**解決方法:**
- もしログが表示されない場合、JavaScriptエラーが発生している可能性があります
- Console に赤いエラーメッセージがないか確認してください

### 3. 予約番号とメールアドレスが一致しない

**症状:**
- ログインフォームで予約番号とメールアドレスを入力しても「予約が見つかりませんでした」と表示される

**確認事項:**
1. メールアドレスが予約時に入力したものと完全に一致しているか
2. 予約番号が正しいか（5桁の小文字英数字）
3. 予約番号に余分なスペースが入っていないか

**解決方法:**
- 予約確認メールに記載されている予約番号とメールアドレスを正確にコピー&ペースト
- 予約番号は小文字で入力（自動的に小文字に変換されます）

### 4. サーバーエラー

**症状:**
- 「ログインに失敗しました」というエラーメッセージが表示される
- ページの読み込みが途中で止まる

**診断手順:**
1. ブラウザの開発者ツールを開く（F12キー）
2. Network タブを確認
3. `/public/my-reservation-login` リクエストを探す
4. レスポンスの Status Code とレスポンス内容を確認

**解決方法:**
- Status Code が 500 の場合: サーバーエラーです。Supabase のログを確認してください
- Status Code が 404 の場合: API エンドポイントが見つかりません。サーバーが正しくデプロイされているか確認してください
- Status Code が 401 の場合: メールアドレスまたは予約番号が間違っています

## デバッグモード

最新版では、詳細なデバッグログがコンソールに出力されます。

### ログの確認方法

1. ブラウザで `/my-reservation` にアクセス
2. F12 キーで開発者ツールを開く
3. Console タブを選択
4. 以下のログが出力されるはずです:

```
[App] 初期ルート: /my-reservation
[App] 予約確認ページ表示: /my-reservation
[MyReservation] ページ読み込み
[MyReservation] 現在のURL: https://...
[MyReservation] パス: /my-reservation
[MyReservation] 検索パラメータ: ?number=abc12&email=test@example.com
[MyReservation] URLパラメータ: { number: 'abc12', email: 'test@example.com' }
```

メールのリンクから自動ログインする場合:
```
[MyReservation] 自動ログイン開始
[MyReservation] ログイン試行: { email: 'test@example.com', reservation_number: 'abc12' }
[MyReservation] レスポンスステータス: 200
[MyReservation] ログイン成功: { reservation: {...}, work_orders: [...] }
```

```
[MyReservation] エラー詳細: { message: '予約が見つかりませんでした', stack: '...' }
```

## よくある質問

### Q: メールが届かない

A: メール送信には Brevo API を使用しています。以下を確認してください:
1. `BREVO_API_KEY` 環境変数が正しく設定されているか
2. 迷惑メールフォルダに入っていないか
3. メールアドレスが正しく入力されているか

### Q: 予約番号がわからない

A: 予約確認メールに記載されています。メールが見つからない場合は、店舗にお問い合わせください。

### Q: URLパラメータ付きでアクセスしても自動ログインされない

A: 以下を確認してください:
1. URLが完全にコピーされているか（`?number=...&email=...` を含む）
2. ブラウザのConsoleにエラーが表示されていないか
3. 予約番号とメールアドレスが正しいか

## サポートが必要な場合

上記の手順で解決しない場合は、以下の情報を添えて問い合わせてください:

1. ブラウザの種類とバージョン
2. アクセスしたURL
3. ブラウザのConsoleに表示されたエラーメッセージ（スクリーンショット推奨）
4. 予約番号（個人情報は除く）
5. 発生している具体的な症状
