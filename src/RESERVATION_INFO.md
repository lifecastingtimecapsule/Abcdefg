# アマレット予約システム - アクセス情報

## お客様用予約ページ

**URL:** `/reservation` または `/yoyaku`

お客様はこのURLから予約を行えます。
- カレンダーから日付を選択
- メニューを選択
- お客様情報を入力
- 仮予約完了後、確認メールが自動送信されます

### 予約の流れ

1. **日時とメニュー選択**
   - カレンダーから希望日を選択
   - 時間帯を選択（9:00〜18:00、30分刻み）
   - メニューを選択
   - 店舗を選択（デフォルト：豊川店）

2. **お客様情報入力**
   - 保護者様のお名前 *
   - お子様のお名前 *
   - お子様の年齢（歳・ヶ月）
   - 電話番号 *
   - メールアドレス *
   - 郵便番号
   - 住所
   - 備考・ご要望

3. **確認・送信**
   - 入力内容を確認
   - 「予約を確定する」ボタンをクリック
   - 仮予約完了
   - 確認メールが届きます

### 重要事項

- こちらは**仮予約**です
- スタッフから確認のお電話をさせていただきます
- お電話での確認をもって正式な予約確定となります

## スタッフ用管理画面

**URL:** `/admin-sys-login`

⚠️ このURLは外部には公開しないでください。

### ログイン情報

- **ログインID:** admin
- **パスワード:** amaretto2024

スタッフ用管理画面では以下の機能が利用できます：
- 予約管理（予約の閲覧・編集・日時変更・削除）
- 顧客管理
- 作品管理
- 納期管理
- インセンティブ管理
- 運用管理（店舗管理、スタッフ管理、メニュー設定）

### 予約の編集方法

1. カレンダーページで予約をクリック
2. 予約詳細が表示されます（閲覧モード）
3. 「編集」ボタンをクリックして編集モードに切り替え
4. 日付、時間、メニュー、店舗などを変更
5. 「保存」をクリックして変更を確定

### メニュー管理

運用管理 > メニュー設定から以下の操作が可能です：
- メニューの追加・編集・削除
- 基本料金の設定
- 追加単価の設定
- メニューの説明文
- メニューの有効/無効切り替え

**デフォルトメニュー：**
- お好きな部位一本+写真（15,000円、追加単価5,000円）
- お好きな部位二本+写真（20,000円、追加単価5,000円）
- ご家族全員の手+写真（25,000円、追加単価5,000円）

## メール送信について

予約完了時に自動的に確認メールが送信されます。

### メール設定

メール送信には **Resend API** を使用しています。
環境変数 `RESEND_API_KEY` に APIキーを設定してください。

Resend API キーの取得方法：
1. https://resend.com/ にアクセス
2. アカウントを作成
3. API Keysから新しいキーを作成
4. 取得したキーを環境変数に設定

## 技術仕様

- **フロントエンド:** React + TypeScript + Tailwind CSS
- **バックエンド:** Supabase Edge Functions (Deno + Hono)
- **データベース:** Supabase KV Store
- **メール送信:** Resend API
- **認証:** Supabase Auth

## セキュリティについて

- お客様用予約ページは認証不要（公開API）
- スタッフ用管理画面は認証必須
- スタッフ用ログインURLは分かりにくいパスに設定
- デフォルトルート（/）は自動的に予約ページへリダイレクト
